# 起飛之前 · Before Takeoff

桃園與高雄出發的航班查詢與行程規劃網站，以清楚的航空公司、班號、日期、兩地時間與機場資訊，協助使用者安排出國來回行程。

> 此儲存庫保存程式碼，不包含原作者蒐集的航班資料、金鑰、登入憑證或本機設定。網站查不到某班機，不代表該航線沒有營運；航班資訊亦不代表可售機位。

## 主要功能

- 桃園（TPE）與高雄（KHH）出發查詢，依目的地、國家、日期、時間與航空公司篩選。
- 選擇去程與回程，以統一精簡卡片比較班次，選好後查看完整來回行程。
- 顯示當地起降時間、跨日資訊與時區，區分預定班表、即時動態與待核對資訊。
- 可拖曳的懸浮旅行工具：AI 航班助理、本次行程入口、搭機與轉機流程指南。
- AI 航班助理使用後端 Google Cloud Vertex AI，整理自然語言需求及已收錄班表；金鑰與驗證資料不送到瀏覽器。
- 保存資料來源與核對狀態，來源衝突不自行推算覆蓋。

「我的行程」目前僅查看本次頁面選擇，尚未支援跨次儲存。自動轉機配對與即時票價比較尚未完成；AI 不應把資料缺漏解讀為沒有航班。

## 技術架構

Next.js 16 App Router、React 19、TypeScript，使用 pnpm 管理依賴，Node.js 測試工具執行測試。航班資料供應器、查詢服務與畫面元件分離。

| 目錄 | 用途 |
|---|---|
| `src/app/` | 網頁入口、API 與樣式 |
| `src/frontend/flights/` | 搜尋、來回行程與 AI 助理畫面 |
| `src/features/flights/` | 前後端共用的航班型別、時區與篩選規則 |
| `src/server/services/` | 後端航班查詢與資料整合 |
| `src/server/providers/` | 後端航空公司及機場資料來源轉換 |
| `src/server/data/` | 本機航班快照（不隨儲存庫上傳） |
| `scripts/` | 本機資料處理、蒐集及核對工具 |
| `tests/` | 功能、時區、資料規則與來源檢查 |
| `public/` | 網站靜態資產與字型授權聲明 |

## 本機啟動

需要 Node.js 20.9 以上，以及 pnpm 11。

```bash
pnpm install --frozen-lockfile
pnpm run setup:data
```

初始化只建立空白本機資料檔，不會覆蓋已存在的資料。原作者的蒐集資料並未隨程式碼提供。若要先體驗畫面，建立 `.env.local`：

```dotenv
FLIGHT_DATA_MODE=demo
```

```bash
pnpm dev
```

開啟 http://127.0.0.1:3000/ 。示範資料為虛構，不可作為旅行依據；示範模式也不代表有完整回程或 AI 查詢資料。

正式資料模式可參考 `.env.example` 設定 `FLIGHT_DATA_MODE=official`。機場公開資料受來源可用性影響，歷史與未來日期需要自行取得並核對資料，依各來源使用條款處理；勿將爬蟲的存在視為重新散布資料的授權。

## AI 助理（選用）

沒有 Google Cloud 設定時，其他查詢與畫面功能仍可獨立使用。啟用 AI 時，於本機環境設定自己的 Google Cloud 專案與模型，並完成伺服器端 Application Default Credentials 驗證。變數名稱請看 `.env.example`。

Google Cloud 的模型請求可能收費，依自己的帳戶方案與用量確認。不要把 API key、服務帳號 JSON 或 Google Cloud 憑證加入 Git，亦不要使用 `NEXT_PUBLIC_` 儲存機密資料。

## 檢查與建置

```bash
pnpm typecheck
pnpm test
pnpm build
pnpm start
```

部分測試是針對原作者的已核對航班快照與原始證據，需在本機恢復相應資料後才可執行通過；此程式碼版本未附那些資料。Google Cloud 連線與模型請求亦需要自行設定。

## 雲端部署

公開網站可部署在 Google Cloud Run。GitHub 儲存庫沒有航班快照，因此直接從此儲存庫部署時只能使用空資料或示範模式；要提供目前本機的正式航班查詢，須另行將已核對的資料快照放進部署包，且不得附上 `.env.local`、本機憑證、爬蟲原始紀錄或研究資料。雲端執行時使用服務帳號取得 Vertex AI 授權，不需上傳個人登入憑證；自動核對程序只在本機執行。

公開 AI 助理在單一執行個體中設有每來源每小時 5 次、總計每小時 60 次的基本限制。執行個體重新啟動會重設計數，這不是保證支出上限；Cloud Run、建置、映像儲存及 Vertex AI 可能產生費用，請在 Google Cloud 設定預算通知並監看用量。

## 資料與隱私

本儲存庫明確排除 `.env.local`、金鑰、私鑰、服務帳號憑證、`src/server/data/*.json`、`data/` 原始樣本與快取、執行紀錄、依賴及建置產物。空資料模板不含任何航班觀察。全球機場與國家等查詢用參考目錄、字型及其既有授權聲明保留於原位置。

這是行程規劃工具，不提供訂位服務。出發前請以航空公司與機場的最新公告為準。
